# AI Context Consent & Construction

TrackX enforces data-minimization rules when feeding context data to AI models.

## Selectivity & Filter Rules
- Query-specific filters: When a student asks about "DBMS", only DBMS attendance ratios and schedule entries are included in the prompt context.
- Consent toggles: Students can toggle sharing categories (Attendance, Timetable, Tasks, Assignments, Exams, CGPA, Notes) under AI settings.
- Consent previews: Shows a prompt preview before making the query so students know exactly what is shared.
