# v1 Deprecation Plan

This plan outlines the timeline for legacy v1 services decommissioning.

## Milestones

- **Launch (Month 0)**: Rollout v2.0.0.
- **Opt-In Phase (Month 1-3)**: Offer simple migrations in the Profile settings.
- **Enforcement (Month 4)**: Legacy client API access rejected, prompting update link cards.
- **Decommission (Month 6)**: Archive v1 sync databases and release final backups.
