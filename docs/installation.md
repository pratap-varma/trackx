# Installation Guide

You can download and install TrackX directly on your mobile device.

## Android Installation

1. Open the [GitHub Releases](https://github.com/yourusername/trackx/releases) page on your Android device.
2. Download the universal APK (`TrackX-v1.0.0-universal.apk`).
3. If prompted by your browser, tap **Settings** and enable **Allow installation from this source**.
4. Open the downloaded APK file and click **Install**.
5. Launch **TrackX** from your app drawer.

## iOS Installation

iOS builds are currently available for developer deployment only. To install:
1. Open the project in Xcode on a macOS device.
2. Connect your iPhone.
3. Configure your provisioning profile and select **Product > Run** to install directly.
