# Security Policy

## Supported Versions

Only the latest release version of TrackX is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:
1. Do not open a public GitHub issue.
2. Email your findings privately to `security-report@example.com` (placeholder contact).
3. Include detailed steps to reproduce the issue, along with any relevant payloads or screenshots.

We aim to acknowledge receipt of your report within 48 hours and coordinate a patch fix promptly. Thank you for keeping TrackX secure!
