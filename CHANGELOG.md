# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-17

### Added
- **Core Attendance System**: Subject-wise and period-wise daily attendance records, active semester selectors, and safe-to-bunk simulators.
- **Academic Timetable**: Structured daily slot configurations supporting conflict checks and reminders.
- **Productivity Module**: CGPA grade forecasting trackers, task checklists, multiline revision note editors, and holiday planning calendars.
- **Cloud Infrastructure**: Firebase Auth integration, secure Firestore offline queues push/pull engine, and JSON data backup recovery tools.
- **AI Integration**: Apple VisionOS-themed glass chat advisor panels suggesting academic and study tips while maintaining privacy consent configurations.
- **Home-screen Widgets**: Multi-size data serializers keeping desktop widgets updated dynamically.
- **Geofence Suggesters**: Location boundary check confirmation flows near mapped classrooms.
