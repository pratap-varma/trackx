# TrackX Release Roadmap

This document outlines the planned releases, feature prioritizations, and candidate milestones for TrackX development.

## v1.0.x (Current - Stability & Security)
- [x] Firebase sync engine integration
- [x] Hive structured database migration
- [x] Privacy controls settings
- [x] Version checkers and diagnostics collectors
- [ ] Hotfixes and battery optimizations

## v1.1.0 (UX & Accessibility Improvements)
- [ ] CSV and PDF data sheet formatting expansions
- [ ] Screen-readers audio alerts
- [ ] Multiple semesters timeline comparison charts

## v1.2.0 (Smart Automation)
- [ ] OCR timetable image import parser
- [ ] Calendar integration (Google / Outlook import)

## v2.0.0 (Ecosystem Expansions)
- [ ] Desktop dashboard (Web client sync support)
- [ ] Multi-college attendance templates
